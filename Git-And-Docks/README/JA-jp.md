## 自己紹介

プログラムやゲームを作り、音楽を制作し、3Dモデリングやデザインも手がけています。どの分野でも少しずつ上達するのが目標です。プログラミングは2011年から独学で、小学生の頃にNokiaやSony Ericssonのガラケー向けJ2ME（Java）ゲームを改造したのが始まりでした。

<table>
<tr>
<td width="33%" valign="top"><b>ソフトウェア</b><br><sub>デスクトップとWeb：Electron、Qt、PHP、Python。自動化できるものはすべて自動化します。</sub></td>
<td width="33%" valign="top"><b>ゲーム</b><br><sub>Unreal Engine 5で3本のゲームを開発中。Unity、Godot、Sourceの経験もあります。</sub></td>
<td width="33%" valign="top"><b>3D</b><br><sub>BlenderとCinema 4Dでモデリング、RenderManでレンダリング、Substanceでテクスチャ制作。</sub></td>
</tr>
<tr>
<td width="33%" valign="top"><b>音楽</b><br><sub>FL StudioとAbleton。オリジナル曲、カバー、ゲームのサウンドトラック。</sub></td>
<td width="33%" valign="top"><b>デザイン・映像</b><br><sub>FigmaとAdobe XDでUI、Photoshopでグラフィック、Premiere Pro・After Effects・DaVinci Resolve・CapCutで映像編集。</sub></td>
<td width="33%" valign="top"><b>リバースエンジニアリング・MOD</b><br><sub>エンジンやソフトの内部構造を探るのが好きです：Source、Unreal、Unity、Godot、Blender、FL Studio、Ableton。</sub></td>
</tr>
</table>

- **開発中:** Unreal Engine 5で3本のゲーム
- **学習中:** Vue、JavaScript、TypeScript、C++、CMake、Qt、Lua
- **探しているもの:** ゲームやアプリを開発する会社での仕事。オファーやコラボも歓迎です
- **目標:** プログラミングの仕事に就くこと、自分のゲームをすべてリリースすること、レーベル・ツール・フレームワークなど誰かの創作を支えるものを作ること
- **気軽にどうぞ:** 何でも聞いてください。特に創作の話なら大歓迎。どんなアイデアでもお手伝いします
- **分野:** フロントエンド、バックエンド、フルスタック、ゲーム開発、モバイル、3D、ML、デザイン
- **ゲームジャム:** Ludum Dare 2023
- **コード以外:** 音楽、ゲーム、お絵描き
